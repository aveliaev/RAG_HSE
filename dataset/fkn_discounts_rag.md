# Скидки на обучение — НИУ ВШЭ (бакалавриат / специалитет)

**Источник:** Положение о предоставлении скидок по оплате обучения НИУ ВШЭ  
**Применяется:** программы бакалавриата и специалитета, включая программы ФКН

---

## Централизованные скидки при поступлении

При поступлении на программы бакалавриата/специалитета скидка может быть установлена по одному из следующих оснований:

- **По результатам вступительных испытаний** — сумма баллов по всем испытаниям без учёта индивидуальных достижений.
- **По итогам обучения на факультете довузовской подготовки** ВШЭ.
- **По итогам обучения в Лицее НИУ ВШЭ.**
- **По итогам обучения в школах распределённого лицея НИУ ВШЭ.**
- **По итогам обучения в базовых и ключевых региональных школах / региональных центрах** НИУ ВШЭ.
- **Детям работников НИУ ВШЭ** (кроме работающих на условиях внешнего совместительства).

> **Важно:** скидка **не сохраняется** при переводе студента на другую образовательную программу НИУ ВШЭ.

При наличии права на скидку по нескольким основаниям предоставляется **одна** скидка по выбору студента.

Централизованные скидки **не предоставляются** студентам полностью платных программ (без бюджетных мест), если иное не установлено Положением.

Скидки за счёт бюджета факультета **не суммируются** с централизованными скидками.

---

## Скидка по результатам обучения (в процессе учёбы)

Скидка по итогам учёбы может быть предоставлена студентам **с 1-го курса** (начиная со 2-го года обучения, по итогам предыдущего учебного года).

**Размер скидки: от 25% до 70%.**

### Условия получения (студенты, поступившие до 2026 года набора)

Все условия должны выполняться **одновременно** в течение предшествующего учебного года:

1. Студент **не имеет дисциплинарного взыскания** в виде выговора.
2. По результатам промежуточной аттестации **до пересдач** по всем элементам учебного плана:
   - **не более двух** оценок 4 и/или 5 баллов по десятибалльной шкале;
   - **нет оценок ниже 4** баллов по десятибалльной шкале;
   - **нет неявок** на аттестационные испытания без уважительной причины.

### Когда назначается скидка

- **Летний период** — студентам, завершившим сессию 3 и 4 модулей в срок: на основании текущего рейтинга **после пересдач 1 полугодия** и **до пересдач 2 полугодия**.
- **Осенний период** — студентам, не участвовавшим в сессии 3 или 4 модулей по уважительной причине: после окончания периода пересдач, на основании текущего рейтинга после пересдач.

---

## Основания для лишения скидки

Студент **лишается скидки**:

1. **Любой скидки** — если объявлен **выговор** за нарушение устава, Правил внутреннего распорядка или иных локальных актов НИУ ВШЭ.

2. **Централизованной скидки за поступление** (кроме скидки по результатам вступительных испытаний) — при несоответствии критериям успешного обучения:
   - более двух оценок 4 и/или 5 баллов по результатам промежуточной аттестации **до пересдач**;
   - оценка ниже 4 баллов по результатам промежуточной аттестации **до пересдач**;
   - неявка на форму контроля без уважительной причины.

3. **Централизованной скидки по результатам обучения** — при наличии **незакрытой академической задолженности** после окончания периода пересдач.

> **Важно:** после лишения скидки её действие **не возобновляется**.

## Скидки для иностранных студентов

Скидки предоставляются иностранным гражданам **с момента зачисления** и сохраняются на весь период обучения при соответствии критериям успешного обучения.

### Критерии успешного обучения для иностранцев

Применяются **начиная со 2-го курса** (1-й курс не учитывается):

1. Нет дисциплинарного взыскания в виде выговора.
2. По каждой промежуточной аттестации по всем элементам учебного плана:
   - **нет оценок ниже 4** баллов по 10-балльной шкале (после пересдач);
   - **не более 2** оценок 4 и/или 5 баллов по 10-балльной шкале.

### Основания для скидки иностранным студентам при поступлении

- По результатам вступительных испытаний.
- По итогам освоения дополнительных образовательных программ Центра подготовки иностранных слушателей или программ русского языка как иностранного, реализуемых НИУ ВШЭ.
- По итогам участия в олимпиадах, проводимых НИУ ВШЭ.
- Выпускникам школ-партнёров НИУ ВШЭ (с договорами о сотрудничестве).
- За **раннее заключение договора** об оказании платных образовательных услуг и оплату стоимости обучения.

Иностранному гражданину устанавливается только **одна** скидка. При праве на несколько — выбирает сам.

## Ключевые правила — кратко

| Ситуация | Правило |
|----------|---------|
| Несколько оснований для скидки | Выбираешь одну — наиболее выгодную |
| Перевод на другую программу ВШЭ | Скидка не сохраняется |
| Полностью платная программа (без бюджета) | Централизованная скидка не предоставляется |
| Скидка от факультета + централизованная | Не суммируются |
| Лишили скидки | Восстановление невозможно |
| Иностранец, 1-й курс | Критерии успешности не применяются |
| Размер скидки за успеваемость | 25–70% |
